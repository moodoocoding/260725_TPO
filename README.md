# TPO 스타일 구조대

문자 메시지에 담긴 시간(Time), 장소(Place), 상황(Occasion) 단서를 읽고
제한 시간 안에 안전하고 알맞은 옷을 완성하는 웹 옷입히기 게임입니다.

현재 버전은 스토리 모드의 첫 번째 에피소드인 **비 오는 날 마트 심부름**을
처음부터 결과 피드백까지 플레이할 수 있습니다. 로그인 화면은 미리 보기이며,
실제 인증은 아직 연결하지 않았습니다.

## 실행

```bash
npm install
npm run dev
```

## 아트 에셋

캐릭터와 16개 옷·소품은 같은 1024×1536 캔버스의 투명 WebP 레이어로
조합됩니다. 새 에셋을 만들거나 검증할 때는 아래 명령을 사용합니다.

```bash
npm run art:generate
npm run art:validate
```

이미지 로드에 실패하면 게임이 중단되지 않고 기존 CSS 캐릭터로 자동
전환됩니다.

## 현재 검증 단계

에피소드 2를 만들기 전에 첫 에피소드의 아동 사용성을 검증합니다. 진행
대본, 아이템 식별 카드, 참가자 기록지와 결과 판정표는
[`docs/usability`](docs/usability/README.md)에 있습니다.

## 저장 방식

현재 버전은 별도 데이터베이스를 사용하지 않습니다. 최고 점수와 진행 정보는
사용자의 브라우저에만 저장되며, 로그인·랭킹·배틀처럼 여러 기기에서 공유해야
하는 기능까지 검증한 뒤 마지막 단계에서 Supabase 연계를 검토합니다.
