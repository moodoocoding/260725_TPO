# TPO 스타일 구조대

문자 메시지에 담긴 시간(Time), 장소(Place), 상황(Occasion) 단서를 읽고
제한 시간 안에 안전하고 알맞은 옷을 완성하는 웹 옷입히기 게임입니다.

현재 버전은 스토리 모드의 첫 번째 에피소드인 **비 오는 날 마트 심부름**을
처음부터 결과 피드백까지 플레이할 수 있습니다. 로그인 화면은 미리 보기이며,
실제 인증은 아직 연결하지 않았습니다.

## 실행

```bash
npm install
npm run dev
```

## Supabase 연결

`.env.example`을 참고해 환경 변수를 설정하고 `supabase/schema.sql`을 실행하면
플레이 결과가 `story_runs` 테이블에 저장됩니다. 서비스 역할 키는 서버 환경에만
설정해야 합니다.
