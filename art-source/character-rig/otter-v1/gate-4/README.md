# Gate 4 — 1화 정답 코디 아트 버티컬 슬라이스

상태: 정적 화면 검토 대기

## 정답 코디

| 슬롯 | 아이템 | TPO 기능 |
|---|---|---|
| 상의 | 구조 훈련복 | 밝은 색과 반사 띠로 가시성 확보 |
| 하의 | 활동 바지 | 움직임과 무릎 보호 |
| 신발 | 논슬립 운동화 | 미끄럼 방지와 빠른 이동 |
| 소품 | 안전모 | 머리 보호와 가시성 |

반사 밴드와 가방은 Gate 3의 겹침 검증에만 사용했다. 실제 4슬롯 정답에서는 반사 기능을 상의에 통합하고 안전모만 소품으로 사용한다.

## 제작 원칙

- 모든 의상은 `otter-v1.0.0`의 1024×1536 좌표를 공유한다.
- 캐릭터 착용 레이어와 카드 썸네일은 동일한 SVG 원본을 사용한다.
- 상의와 안전모는 앞·뒤 레이어로 분리한다.
- 아이템별 CSS 위치 보정은 사용하지 않는다.
- 기존 게임 코드와 공개 배포 에셋은 아직 변경하지 않는다.

## 검토 파일

- `vertical-slice.svg`: 1화 전체 정적 화면
- `vertical-slice-final.png`: 최종 렌더링 검토본
- `outfit-composite.svg`: 정답 코디 합성
- `outfit-composite-final.png`: 정답 코디 최종 렌더링 검토본
- `otter-base.png`: Gate 3 승인 원본의 Gate 4 고정 복사본
- `card-*.svg`: 동일 원본 기반 카드 썸네일
- `assets-manifest.json`: 아이템 메타데이터와 레이어 경로
