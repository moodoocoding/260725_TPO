# Gate 5 — 매력적인 오답과 기능 피드백

상태: 정적 검토 완료, 사용자 승인 대기

## 오답 아이템

| 슬롯 | 오답 | 현재 상황에서 부족한 기능 | 잘 맞는 다른 상황 |
|---|---|---|---|
| 상의 | 멋진 정장 재킷 | 가시성과 움직임 | 발표회, 격식 있는 자리 |
| 하의 | 긴 나들이 치마 | 빠른 이동 | 천천히 걷는 나들이 |
| 신발 | 포근한 실내 슬리퍼 | 고정력과 미끄럼 방지 | 집 안에서 휴식 |
| 소품 | 피크닉 바구니 | 손의 자유와 머리 보호 | 공원 소풍 |

## 피드백 원칙

- 아이템 자체를 나쁘거나 우스운 것으로 표현하지 않는다.
- “틀렸다”보다 현재 상황에 필요한 기능을 다시 제시한다.
- 각 오답이 잘 맞는 다른 상황을 함께 알려준다.
- 외형 취향이 아니라 움직임·가시성·보호 기능으로 설명한다.

## 승인 조건

- 오답도 고르고 싶을 만큼 매력적으로 보인다.
- 카드와 착용 결과가 같은 물건으로 보인다.
- 글을 읽지 않아도 정답과 오답의 기능 차이를 일부 추론할 수 있다.
- 피드백이 벌이나 조롱처럼 느껴지지 않는다.
- 아이가 “다른 상황에서는 맞을 수 있다”는 점을 이해할 수 있다.
