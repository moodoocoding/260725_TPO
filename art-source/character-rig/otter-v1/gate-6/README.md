# Gate 6 아동 검증 패키지

## 목적

1화 아트 버티컬 슬라이스가 실제 아동에게 다음 순서로 이해되는지 확인한다.

1. 글을 읽기 전에도 구조대 훈련 상황과 핵심 의상을 구분한다.
2. 의상 카드와 캐릭터의 착용 결과를 같은 물건으로 인식한다.
3. 취향이 아니라 상황과 옷의 기능을 연결해 선택 이유를 설명한다.
4. 오답 피드백을 받은 뒤에도 다시 고르거나 다음 에피소드를 시도하려 한다.

## 검증용 자극

- `stimulus-a-correct-outfit.png`: 5초 첫인상 검증용 정답 착용 장면
- `stimulus-b-wrong-outfit.png`: 오답 착용 비교 장면
- `stimulus-c-choice-matrix.png`: 부위별 정답·오답 선택 화면
- `stimulus-d-feedback.png`: 비난하지 않는 오답 피드백 화면
- `stimulus-e-outfit-comparison.png`: 정답·오답 착용 자연스러움 비교 화면

- 관찰·자동 집계 XLSX: `outputs/019f997b-c234-7293-8f15-575be882b144/TPO_Gate6_아동검증_관찰기록.xlsx`

## 권장 운영

- 형성 검증: 최소 6명, 반복되는 문제를 찾는 단계
- 의사결정 검증: 권장 18명, Gate 7 진입 여부를 판단하는 단계
- 아동 1명당 10-12분
- 이름 대신 `T01`, `T02` 형태의 참여자 ID만 사용
- 보호자 동의를 확인하고, 아동이 원하면 언제든 중단

## Gate 7 진입 기준

- 5초 내 상황 인지 80% 이상
- 네 부위 정답 평균 75% 이상
- 카드-착용 일치 90% 이상
- 착용 자연스러움 90% 이상
- 레이어 어색함 발견 10% 이하
- TPO 설명 2점 이상 70%
- 재시도 및 다음 화 의향 75% 이상

실제 검증 결과를 XLSX에 입력한 뒤 `요약` 시트의 `GO`, `REVISE`, `STOP` 판정을 사용한다. 선택·일치·착용 자연스러움에서 중대한 문제가 반복되면 전체 통과 개수와 무관하게 해당 에셋을 먼저 수정한다.
