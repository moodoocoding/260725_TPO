# Gate 6 모의 아동 검증 보고서

> 이 문서는 실제 아동을 대상으로 한 사용성 검증 결과가 아니다. Gate 6 평가표가 어떤 결론을 내릴지 사전에 점검하기 위한 합성 데이터 기반 시뮬레이션이다.

## 실행 목적

- 실제 검증 전에 캐릭터·의상 시스템의 취약 지점을 찾는다.
- 18명처럼 작은 표본에서 Gate 기준이 얼마나 민감하게 작동하는지 확인한다.
- Gate 7 코드 통합 전에 수정 우선순위를 정한다.

## 시뮬레이션 설계

- 기준일: 2026-07-26
- 고정 시드: `20260726`
- 대표 실행: 가상 참가자 18명
  - 1~2학년군 9명
  - 3~4학년군 9명
- 반복 실행: 10,000회
- 판정 규칙
  - 미달 항목 0개: `GO`
  - 미달 항목 1~2개: `REVISE`
  - 미달 항목 3개 이상: `STOP`

학년군별 성공 확률은 저학년이 상황 설명과 전이 문항에서 더 어려움을 겪고, 고학년이 더 높은 성공률을 보이도록 보수적으로 설정했다. 이 확률은 관찰 데이터가 아니라 검증 도구의 사전 점검을 위한 가정이다.

## 해석

첫째, 카드 그림과 실제 착용 모습의 형태·색상 일관성이 더 필요하다. 아이가 카드와 착용 결과를 같은 물건으로 즉시 연결하지 못할 가능성이 있다.

둘째, 손·허리·액세서리 접점의 레이어가 어색하게 보일 가능성이 있다. 단순히 이미지를 겹치는 방식이 아니라 의상별 가림 영역과 앞뒤 순서를 명시해야 한다.

셋째, 정답을 고르는 것과 새로운 TPO에 원리를 전이하는 것은 별개의 문제다. 결과 화면에 “왜 이 옷이 맞을까?”를 짧게 설명하게 하고, 다른 상황을 한 번 더 제시하는 전이 문항이 필요하다.

넷째, 18명 표본에서 90% 기준은 매우 민감하다. 16명 성공은 88.89%로 미달이고 17명 성공은 94.44%로 통과한다. 레이어 어색함도 1명 발견은 5.56%로 통과하지만 2명은 11.11%로 미달한다. 한 명의 반응만으로 판정이 바뀌므로 실제 파일럿에서는 경계 구간을 별도로 표시하거나 표본을 30명 안팎으로 늘리는 것이 안전하다.

## Gate 7 권고

현재 결론은 `REVISE 후 재검증`이다. 합성 데이터의 `STOP`을 실제 제품 실패로 확정하지는 않지만, 아래 항목을 수정하기 전 전체 에피소드 통합은 보류한다.

1. 카드와 착용 에셋의 실루엣·색상·장식 일치
2. 손, 허리, 신발, 액세서리의 가림 마스크와 레이어 순서
3. 결과 화면의 TPO 이유 설명과 새 상황 전이 문항
4. 18명 파일럿용 경계 판정 규칙 또는 표본 확대

수정 후에는 먼저 소규모 실제 아동 파일럿을 진행하고, 반복되는 문제가 없을 때 Gate 7 통합으로 넘어간다.

## 1차 보완 후 재시뮬레이션

2026-07-26에 다음 보완을 구현한 뒤, 구현으로 직접 달라진 항목만 확률 가정을 조정하여 10,000회 다시 실행했다.

- 인간형 1화 캐릭터를 승인된 `otter-v1` 수달로 교체
- 부위별 선택지를 4개에서 2개로 축소
- 카드와 착용 레이어가 동일한 SVG 원본을 사용하도록 v4 에셋 파이프라인 구축
- 상의 `back/main`, 안전모·바구니 `back/front` 레이어 순서 적용
- 결과 화면에 TPO 이유 단서·예시 문장 추가
- 새로운 비 오는 저녁 상황의 전이 문제 추가
- 전이 정답 전에는 다음 임무 버튼을 잠금

캐릭터 호감, 재시도, 다음 화 의향처럼 구현만으로 확정할 수 없는 항목은 이전 확률을 유지했다.

| 판정 | 최초 모의 검증 | 보완 후 재시뮬레이션 |
|---|---:|---:|
| GO | 2.13% | 24.78% |
| REVISE | 34.70% | 64.36% |
| STOP | 63.17% | 10.86% |

카드-착용 일치 기준 통과 확률은 56.73%에서 94.56%, 착용 자연스러움은 60.72%에서 92.33%, 레이어 어색함은 57.34%에서 92.76%, 새 상황 전이는 49.33%에서 95.56%로 상승했다.

모의 판정의 최빈값은 `REVISE`다. 즉, Gate 6의 핵심 구조 문제는 크게 줄었지만 실제 아동의 캐릭터 호감, 다시 플레이 의향, 상황 인지와 작은 표본의 경계 민감도를 확인하기 전에는 Gate 7 전체 통합을 확정하지 않는다.
