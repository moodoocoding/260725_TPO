# 작은귀수달 캐릭터 리그 v1

상태: **Gate 3 시험 착용 구조 통과**

## 승인된 기준

- 캐릭터: 작은귀수달
- 스타일: 한 단계 음영형 플랫 벡터
- 캔버스: 1024 × 1536
- 자세: 정면 중립 자세
- 꼬리: 앞에서 보이지 않음
- 수염: 얼굴 레이어와 충돌하지 않는 짧은 볼 표시

## 기준 파일

- `gate-3/otter-base-keyed.png`: 배경 제거 전 키 원본
- `gate-3/otter-base.png`: 투명 배경 기준 캐릭터
- `rig-spec.json`: 앵커, 슬롯, 앞뒤 순서와 가림 규칙
- `rig-map.svg`: 앵커 위치 확인용 도면

## 이미지 생성 프롬프트 요약

Codex 내장 이미지 생성으로 승인된 스타일 2 수달을 그대로 유지하면서 `1024×1536` 정면 전신, 한 캐릭터만, 썸네일·의상·소품·그림자 없음, 완전한 `#00ff00` 키 배경으로 생성했다. 꼬리는 앞에서 보이지 않고 수염은 짧은 볼 표시로 유지했으며, 팔·다리·발을 분리해 의상 앵커가 보이도록 제한했다.

시험 상의는 동일 캔버스와 몸 비율을 참조해 산호색 짧은 소매 후드, 네이비 외곽선, 한 단계 음영, 캐릭터 없이 의상만 생성했다. 한 장짜리 결과의 후드 겹침 문제가 확인되어 최종 시험 레이어는 좌표 기반 SVG로 분리했다.

1. 짧은 소매 후드 상의

## 시험 결과

처음 생성한 `gate-3/top-single-layer-test-keyed.png`는 후드와 몸통을 한 레이어로 사용하면 후드가 얼굴 앞에 놓이는 문제를 재현했다. 따라서 다음과 같이 앞·뒤 레이어를 분리했다.

- 후드 상의: `top-back` + `top-main`
- 구조 모자: `headwear-back` + `headwear-front`
- 가방: `bag-back` + `bag-front`
- 바지·운동화·반사 밴드: 각 슬롯의 앞 레이어

1차 합성에서 발견된 바지 바깥쪽 기본 다리 노출과 모자 뒤쪽 이중선을 수정했다. 2차 합성 검사는 다음 조건을 통과했다.

- 옷 아래로 의도하지 않은 기본 몸이 보이는 사례: 0건
- 팔·다리·꼬리가 사라지는 사례: 0건
- 공중에 뜨는 소품: 0건
- 신발과 바닥선 분리 오류: 0건
- 캐릭터 위치 변화: 0px
