# TPO 스타일 구조대 아트 스타일 가이드 v1

## 1. 목적

이 문서는 첫 번째 아트 버티컬 슬라이스인 **‘비 오는 날 마트 심부름’**의 캐릭터, 의상, 소품, 배경을 같은 규칙으로 제작하기 위한 기준이다.

아트의 목표는 단순한 장식이 아니다.

1. 아이가 글을 읽기 전에 아이템의 종류를 구분할 수 있어야 한다.
2. 그림에서 방수, 시인성, 활동성, 미끄럼 방지 같은 기능을 추론할 수 있어야 한다.
3. 아이템이 늘어나도 캐릭터와 기존 화면을 다시 그리지 않아야 한다.
4. 오답 아이템도 ‘나쁜 옷’이 아니라 현재 TPO에 덜 적절한 옷으로 보여야 한다.

기준 콘셉트 시트는 `docs/art-style-reference-v1.png`이다.

## 2. 핵심 스타일

- 밝고 따뜻한 아동용 2D 일러스트
- 단순하고 한눈에 읽히는 실루엣
- 네이비 외곽선과 크림색 바탕
- 노랑, 코럴, 민트, 하늘색을 주요 강조색으로 사용
- 재질 묘사는 최소화하고 기능을 보여주는 구조를 강조
- 반실사 표현, 복잡한 질감, 과도한 주름과 장식은 사용하지 않음
- 정답 아이템만 예쁘고 오답 아이템은 못생기게 만드는 표현을 금지

## 4. 캐릭터 기준 규격

### 4.1 포즈

- 정면을 바라보는 중립 포즈
- 양발은 어깨너비로 벌리고 지면에 평행하게 배치
- 양팔은 몸통에서 약 12도 떨어뜨려 소매가 서로 겹치지 않게 함
- 오른손은 우산 손잡이를 잡는 기준 손
- 왼쪽 어깨와 손 주변은 장바구니 착용 공간으로 확보
- 하의와 신발의 실루엣이 겹치지 않게 다리를 벌림

### 4.2 캔버스

| 항목 | 규격 |
|---|---|
| 캐릭터·착용·효과 캔버스 | 1024 × 1536px |
| 표시 비율 | 2:3 |
| 전역 기준점 | 하단 중앙 `(512, 1440)` |
| 안전 영역 | X 128–896, Y 64–1456 |
| 화면 기준 크기 | 256 × 384 CSS px |
| 허용 앵커 오차 | 원본 ±8px, 화면 약 ±2px |
| 색상 공간 | sRGB |

캐릭터와 모든 착용 레이어는 동일한 전체 캔버스를 유지한다. 아이템의 내용 영역만 잘라 저장하거나 아이템마다 별도 좌표 보정 값을 사용하지 않는다.

### 4.3 주요 앵커

| 앵커 | 좌표 |
|---|---:|
| 머리 중심 | `(512, 320)` |
| 왼쪽 어깨 | `(350, 610)` |
| 오른쪽 어깨 | `(674, 610)` |
| 왼쪽 손 | `(270, 940)` |
| 오른쪽 손·우산 | `(754, 940)` |
| 허리 중심 | `(512, 915)` |
| 왼쪽 무릎 | `(420, 1190)` |
| 오른쪽 무릎 | `(604, 1190)` |
| 왼쪽 발목 | `(420, 1380)` |
| 오른쪽 발목 | `(604, 1380)` |
| 지면 중심 | `(512, 1440)` |

| 60 | 신발 | 장화, 운동화, 슬리퍼, 구두 |

## 6. 선과 형태

- 원본 기준 주 외곽선 8–12px
- 내부 구분선 5–9px
- 둥근 선끝과 둥근 연결부 사용
- 외곽선은 순수 검정 대신 딥 네이비 사용
- 96×96px에서도 품목을 알아볼 수 있도록 실루엣을 우선
- 작은 단추와 장식은 기능이나 품목 구분에 도움이 될 때만 사용
- 아이템마다 명도와 형태가 배경에서 분리되도록 최소 3:1 수준의 시각 대비 확보

## 7. 기능 단서

| 아이템 | 반드시 보여야 하는 시각 단서 |
|---|---|
| 노란 우비 | 후드, 방수 표면, 긴 소매, 엉덩이를 덮는 길이, 반사 띠 |
| 민트 바람막이 | 가벼운 재질, 지퍼, 짧은 길이, 활동성 |
| 남색 가디건 | 앞 여밈과 니트 구조, 방수 표현 없음 |
| 크림 니트 | 보온성 있는 짜임, 방수 표현 없음 |
| 검정 활동 바지 | 발목이 끌리지 않는 형태, 무릎 활동성, 수납 포켓 |
| 하늘색 청바지 | 일반 데님 절개와 봉제선 |
| 베이지 반바지 | 다리 노출과 짧은 길이 |
| 긴 주름치마 | 젖은 바닥에 닿을 수 있는 길이와 주름 |
| 노란 장화 | 높은 발목, 물막이 구조, 두꺼운 돌기 밑창 |
| 운동화 | 끈과 굴곡 있는 밑창, 방수 표현 없음 |
| 슬리퍼 | 열린 발뒤꿈치와 얕은 밑창 |
| 검정 구두 | 격식 있는 형태와 매끈한 밑창 |
| 투명 우산 | 우산 너머로 얼굴과 전방이 보임 |
| 검정 우산 | 불투명한 캐노피, 야간 배경과 가까운 명도 |
| 반사 밴드 | 빛을 받았을 때 생기는 별도 반사광 |
| 장바구니 | 넓은 수납 공간과 손잡이, 방수 덮개 없음 |

## 8. 런타임 형식

최종 사이트에는 모델이 작성한 SVG를 직접 배포하지 않는다.

- 생성기의 내부 벡터 도형은 빌드 입력으로만 사용
- 캐릭터, 표정, 의상, 소품, 배경, 효과는 최적화된 WebP로 출력
- 캐릭터·착용·효과 레이어는 1024×1536 투명 WebP
- 에피소드 배경은 넓은 무대에 맞춘 1920×1440 불투명 WebP
- 썸네일은 동일 착용 원본에서 파생한 512×384 투명 WebP
- 모든 WebP는 sRGB와 알파 채널을 유지
- 품목명, 설명, 점수, 정답 표시는 이미지에 넣지 않음

결정론적 생성기는 `scripts/generate-art-assets.mjs`이며, 출력 위치는 `public/art/v1`이다.

## 9. 폴더와 이름

```text
public/art/v1/
├─ character/
│  ├─ base.webp
│  └─ faces/
│     ├─ ready.webp
│     ├─ success.webp
│     └─ retry.webp
├─ episodes/rainy-market-errand/
│  ├─ background.webp
│  └─ effects/
│     ├─ rain-back.webp
│     ├─ rain-front.webp
│     └─ reflective-glow.webp
├─ items/{기존-item-id}/
│  ├─ wear-back.webp
│  ├─ wear-main.webp
│  ├─ wear-front.webp
│  └─ thumb.webp
└─ art-manifest.json
```

- 영문 소문자와 하이픈만 사용
- 아이템 폴더명은 게임 데이터의 기존 ID와 정확히 일치
- `wear-back`, `wear-main`, `wear-front` 중 필요한 파일만 생성
- `final`, `new`, `수정본` 같은 상태 단어를 파일명에 사용하지 않음
- 버전은 파일명 대신 상위 `v1`, `v2` 폴더로 관리

## 10. AI 이미지 사용 범위

AI 이미지 생성은 다음 범위에만 사용한다.

- 스타일 방향과 무드보드 탐색
- 배경의 날씨, 색감, 조명 초안
- 표정과 의상 기능을 탐색하는 참고 자료

다음 항목은 AI 생성물을 그대로 최종 사용하지 않는다.

- 기준 캐릭터 몸
- 착용 좌표와 앵커
- 16개 최종 의상 레이어
- 우산과 가방의 앞뒤 레이어
- 품목 썸네일
- 문자, 로고, UI 텍스트

최종 에셋은 동일한 캐릭터 기준 캔버스에서 선, 색, 좌표, 겹침을 수작업으로 정리하거나 결정론적 생성기로 재현한다. 특정 작가나 유명 캐릭터의 스타일을 모방하지 않는다.

## 11. 제작 순서

1. 기준 포즈, 캔버스, 앵커를 동결한다.
2. 노란 우비, 활동 바지, 노란 장화, 투명 우산으로 골든 세트를 만든다.
3. 골든 세트를 실제 화면에서 겹쳐 보고 손, 발, 소매, 우산의 앞뒤를 검증한다.
4. 골든 세트 승인 후 나머지 12개 아이템을 제작한다.
5. 동일한 착용 원본에서 썸네일 16개를 파생한다.
6. 배경과 날씨·반사 효과를 추가한다.
7. 256개 전체 조합 컨택트시트로 겹침을 확인한다.
8. 모바일, 태블릿, 데스크톱에서 크기와 선명도를 확인한다.
9. 아동 관찰 테스트 후 기능 단서만 보정한다.
10. v1을 동결하고 에피소드 2의 아이템 제작에 같은 규칙을 재사용한다.

## 12. 10영업일 빠른 일정

| 일정 | 작업 | 승인 기준 |
|---|---|---|
| 1일차 | 포즈·앵커·팔레트 확정 | 기준 캔버스 동결 |
| 2–3일차 | 골든 세트 4종 | 실제 화면 겹침 통과 |
| 4–6일차 | 남은 12종과 표정 3종 | 품목 식별과 기능 단서 통과 |
| 7일차 | 배경·빗줄기·반사광 | 캐릭터 가독성 유지 |
| 8일차 | 썸네일 파생·WebP 최적화 | 파일명과 용량 기준 통과 |
| 9일차 | 256조합·반응형 검수 | 치명적 겹침 0건 |
| 10일차 | 사용자 확인·보정·v1 동결 | 다음 에피소드 확장 승인 |

## 13. 검수 체크리스트

### 파일과 좌표

- [ ] 캐릭터·착용·효과 레이어가 1024×1536이다.
- [ ] 에피소드 배경이 1920×1440 불투명 WebP이다.
- [ ] 지면 기준점이 `(512, 1440)`에 일치한다.
- [ ] 앵커 오차가 원본 ±8px 이하이다.
- [ ] 16개 아이템 ID와 폴더명이 일치한다.
- [ ] 최종 배포 폴더에 SVG가 없다.
- [ ] 썸네일이 같은 착용 원본에서 파생되었다.

### 기능과 접근성

- [ ] 96×96px에서도 품목을 구별할 수 있다.
- [ ] 투명 우산 너머로 얼굴과 앞쪽이 보인다.
- [ ] 우비와 바람막이의 기능 차이가 보인다.
- [ ] 장화와 운동화의 방수·밑창 차이가 보인다.
- [ ] 반사 밴드는 선택 시 별도 반사 효과가 나타난다.
- [ ] 색상 없이도 실루엣과 외곽선으로 구분할 수 있다.
- [ ] 오답 아이템을 조롱하거나 나쁘게 묘사하지 않는다.

### 조합과 화면

- [ ] 256개 코디 조합에 치명적 클리핑이 없다.
- [ ] 우산대가 손 앞을 정확히 지난다.
- [ ] 가방 본체와 끈이 몸의 올바른 앞뒤에 놓인다.
- [ ] 반사 밴드가 네 종류의 상의 위에 자연스럽게 놓인다.
- [ ] 긴 치마와 네 종류 신발의 경계가 자연스럽다.
- [ ] 360px, 768px, 1440px 너비에서 선명하게 표시된다.
- [ ] 느린 네트워크에서도 이미지 크기 때문에 레이아웃이 움직이지 않는다.

### 사용자 확인

- [ ] 품목명을 가려도 16개 중 13개 이상을 식별한다.
- [ ] 우비, 장화, 투명 우산, 반사 밴드의 기능을 그림으로 설명한다.
- [ ] 선택 후 캐릭터 변화에 재미를 느낀다.
- [ ] 선택 이유를 점수나 색이 아닌 TPO 단서로 설명한다.
- [ ] 새 테스트 아이템 1개를 기존 원본 수정 없이 추가할 수 있다.
