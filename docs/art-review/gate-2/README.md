# Gate 2 수달 캐릭터 스타일 비교

작성일: 2026-07-26  
상태: **스타일 2 승인 완료**  
생성 방식: Codex 내장 이미지 생성

## 공통 수정

- Gate 1에서 승인된 작은귀수달의 정면 자세와 캐릭터 정체성을 유지했다.
- 앞에서 보이던 꼬리를 완전히 숨겼다.
- 얼굴 레이어와 충돌하지 않도록 긴 수염을 볼 안쪽의 짧은 표시로 바꿨다.
- 의상·배경·소품은 추가하지 않았다.

## 스타일 1: 초평면형

파일: `style-1-ultra-flat.png`

- 초기 CSS 캐릭터에 가까운 단순하고 선명한 표현
- 작은 화면에서 가장 빠르게 읽힘
- 음영과 질감을 제거한 평면 채색
- 단점: 무릎·발목 등 리그 기준선과 형태 정보가 약함

## 스타일 2: 한 단계 음영형

파일: `style-2-one-step-shadow.png`

- 평면 채색에 한 단계의 제한된 음영만 사용
- 팔꿈치·손목·골반·무릎·발목 기준선을 유지
- 옷을 입혔을 때 신체 방향과 겹침을 판단하기 쉬움
- 초평면형보다 따뜻하고 완성된 게임 캐릭터로 보임

## 권고

사용자 결정에 따라 **스타일 2: 한 단계 음영형**을 최종 스타일로 선택했다.

스타일 2 승인 후에는 이미지를 그대로 의상 에셋으로 사용하는 것이 아니라, 동일한 체형을 기준으로 머리·몸통·팔·다리·발의 앵커와 가림 규칙을 먼저 설계하는 Gate 3으로 진행한다.
