# Gate 1 캐릭터 실루엣 후보

작성일: 2026-07-26  
상태: **A 작은귀수달 승인 완료**  
생성 방식: Codex 내장 이미지 생성

## 공통 프롬프트 규격

- 한국 초등학생 대상 TPO 옷입히기 웹게임용 2D 캐릭터
- 정면 대칭, 전신, 팔은 몸통에서 조금 떨어지고 다리는 약간 벌린 자세
- 머리는 전체 높이의 약 35~40%
- 어깨·손목·골반·무릎·발목·발의 경계가 분명한 마스크 친화형 구조
- 모자·상의·하의·신발·소품을 덧입히기 쉬운 연속된 표면
- 단정한 네이비 외곽선과 따뜻한 저채도 팔레트
- 흰색에 가까운 검토용 배경, 의상·소품·장면·문자·로고 없음
- 우측 아래에 동일 캐릭터의 120px 가독성 확인용 축소본 포함
- 사람처럼 사실적인 묘사, 애니메이션풍, 복잡한 털, 3D 광택, 과한 그림자 제외

## 후보별 프롬프트 차이

### A. 작은귀수달

짧고 둥근 귀, 작은 주둥이, 몸 뒤로 숨는 가는 꼬리, 크림·캐러멜색의 친근한 수달 마스코트. 특정 기존 캐릭터와 닮지 않도록 요청했다.

검토 메모:

- 장점: 종의 개성과 브랜드성이 가장 강하다.
- 보완: 꼬리가 두 발 사이에 보이며, 수염이 얼굴 소품 마스크에 간섭할 수 있다.

### B. 토끼

모자 영역을 방해하지 않는 짧고 작은 귀, 정면에서는 꼬리가 보이지 않는 토끼 마스코트. 수달 시안의 선 굵기와 리그 구조만 참조했다.

검토 메모:

- 장점: 작은 축소본에서도 종 구분이 매우 쉽다.
- 보완: 생성 결과의 귀가 계획보다 길어 모자 호환성이 낮다.

### C. 강아지

머리 옆에 붙는 매우 짧은 접힌 귀, 작은 주둥이, 정면에서는 꼬리가 보이지 않는 강아지 마스코트. 머리 윗부분을 모자 전용 공간으로 비우도록 요청했다.

검토 메모:

- 장점: 모자·상의·하의·신발 레이어를 가장 안정적으로 얹을 수 있다.
- 보완: 수달보다 종 자체의 고유 브랜드성은 약할 수 있다.

### D. CSS 마네킹

실제 사람이나 특정 연령을 표현하지 않는 추상적인 비닐 게임 토큰. 초기 CSS 캐릭터의 단순성과 명료성을 비교하기 위한 대조군으로, 전신을 노란색·크림색 그래픽 셸로 덮었다.

검토 메모:

- 장점: 가장 단순하고 레이어 마스킹이 쉽다.
- 보완: 동물 후보보다 캐릭터 매력과 이야기성이 약하다.
