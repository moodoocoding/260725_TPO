# TPO 1화 의상 연결부·선택지 수정계획서

- 문서 상태: 전문가 4인 합의안
- 작성일: 2026-07-26
- 대상: 스토리 모드 1화 `구조대 훈련장`
- 목적: 상·하의 연결 불량을 근본적으로 해결하고, 선택지를 TPO 추론 게임에 적합한 수준으로 확장한다.
- 원칙: 이 문서는 구현 전 설계 기준이다. 문서 승인 전에는 이미지 에셋과 게임 코드를 수정하지 않는다.

## 1. 최종 결론

현재 문제는 상의와 하의를 몇 픽셀 옮겨 해결할 수 있는 배치 오류가 아니다. 각 의상이 공유해야 할 **허리 연결 규격이 없고**, 1화만 슬롯당 선택지가 2개로 축소되어 **TPO 판단이 사실상 이분법 문제**가 된 것이 원인이다.

전문가 4인은 다음과 같이 합의했다.

1. 캐릭터 중심과 별도로 의상용 공통 허리 앵커를 고정한다.
2. 상·하의는 `tucked`, `untucked`, `outerwear` 등 착용 방식을 데이터로 선언한다.
3. 슬롯당 선택지는 기본 4개로 복원한다.
4. 현재 8개 에셋은 폐기하지 않고 보정하며, 신규 8개를 추가해 총 16개로 구성한다.
5. 정답은 하나의 외운 조합이 아니라, 기능적 이유에 따라 여러 조합이 통과할 수 있게 한다.
6. 스토리 첫 시도는 학습을 우선하고 시간 점수의 비중은 10%로 제한한다.
7. 625개 착용 상태와 3개 표정까지 자동 합성 검사를 통과한 뒤 아동 검증으로 넘어간다.

## 3. 전문가 4인 토의

### 참여 역할

| 전문가 | 관점 | 핵심 질문 |
|---|---|---|
| 아트 디렉터 | 캐릭터·의상 미술 | 어떤 조합에서도 한 캐릭터가 자연스럽게 옷을 입은 것처럼 보이는가? |
| 아동 UX·학습 연구자 | 초등 사용자 이해·학습성 | 아이가 그림을 비교하고 TPO 이유를 설명할 수 있는가? |
| 테크니컬 아티스트 | SVG 리깅·레이어·자동 검수 | 아이템 추가가 반복 가능하고 오류를 자동으로 찾을 수 있는가? |
| 게임 시스템 디자이너 | 선택·점수·난이도·재도전 | 정답 암기가 아니라 상황 판단을 유도하는가? |

### 토의 1: 연결부를 어디에 맞출 것인가

- 아트 디렉터는 현재 에셋의 실제 중심인 `x=526`을 기준으로 삼아야 수정량이 작고 실루엣이 안정적이라고 제안했다.
- 테크니컬 아티스트는 전체 캔버스 중심인 `x=512`를 기준으로 제안했다.
- 게임 시스템 디자이너는 두 중심을 하나로 섞으면 이후 에셋마다 오차가 재발한다고 지적했다.

합의:

- **캔버스 중심은 `x=512`**, 리깅 및 의상 중심선은 **`x=526`**으로 구분한다.
- 최종 공통 허리 앵커는 **`W=(526,858)`**로 고정한다.
- 모든 의상 파일은 캔버스 전체 좌표를 유지하고, 런타임에서 아이템별 이동·확대 보정을 하지 않는다.

### 토의 2: 상의와 하의는 얼마나 겹쳐야 하는가

- 아트 디렉터는 자연스러운 옷자락을 위해 18~30px의 의도적 겹침을 제안했다.
- 테크니컬 아티스트는 자동 판정의 안정성을 위해 24~36px 범위를 제안했다.

합의:

- 목표 겹침: **24~30px**
- 허용 범위: **20~36px**
- 재작업 판정: **20px 미만 또는 40px 초과**
- 겹침 구간에는 최종 외곽선이 하나만 보여야 한다.
- 벨트, 그림자, 사각형 덮개로 틈을 가리는 방식은 허용하지 않는다.

### 토의 3: 선택지는 3개인가 4개인가

- 아동 UX 연구자는 저학년 첫 플레이에는 3개부터 시작하는 방안도 제안했다.
- 게임 시스템 디자이너는 현재 로그인과 연령 정보가 없어 자동 난이도 분기가 불가능하며, 2개는 비교 학습에 부족하다고 판단했다.

합의:

- 현재 공통 UI는 **슬롯당 4개**를 기본으로 한다.
- 추후 로그인과 학년 정보가 생기면 `안내형 연습 모드`에서만 3개를 제공할 수 있다.
- 4개는 `최적`, `허용 가능한 대안`, `부분 적합`, `명확한 부적합`의 역할을 갖는다.

### 토의 4: 신규 소품은 망토인가 호루라기인가

- 아트 디렉터는 어린이가 한눈에 구분하기 쉬운 망토를 제안했다.
- 아동 UX 연구자와 게임 시스템 디자이너는 망토가 지나치게 우스운 오답으로 보여 추론 없이 제거될 가능성이 높다고 보았다.
- 테크니컬 아티스트는 목걸이형 소품이 목·상의·손 레이어를 검증하기에 더 유용하다고 판단했다.

합의:

- 신규 소품은 **호루라기**로 한다.
- 호루라기는 구조 활동에 일부 도움은 되지만, 보호와 시인성을 완전히 해결하지 못하는 `부분 적합` 역할을 맡는다.

### 토의 5: 정답은 하나여야 하는가

- 아트 디렉터는 대표 정답 조합이 있어야 이야기의 인상이 선명해진다고 보았다.
- 아동 UX 연구자는 하나의 정답만 허용하면 아이가 이유보다 조합을 외우게 된다고 지적했다.

합의:

- 100점 대표 조합은 하나 둔다.
- 전체 256개 완성 조합 중 **8~24개가 통과 점수**를 얻도록 설계한다.
- 안전에 치명적인 아이템이 포함되면 고득점은 제한하되, 피드백은 옷 자체를 비난하지 않고 해당 상황에서 필요한 기능을 설명한다.

### 토의 6: 제한시간은 어떻게 유지할 것인가

- 원래 게임 목표에는 시간 점수가 포함되어 있다.
- 아동 UX 연구자는 첫 시도부터 시간 압박을 주면 글을 읽고 이유를 생각하는 행동이 약해진다고 지적했다.

합의:

- 스토리 첫 시도: 목표 시간 **90초**, 시간 종료 후에도 계속 선택 가능, 자동 실패 없음
- 재도전 빠른 도전: 목표 시간 **60초**
- 총점에서 시간 비중은 **10%**
- 제한시간을 넘기면 시간 보너스만 0점이 되며 TPO 판단 점수는 그대로 채점한다.

## 4. 동결할 리깅 규격

### 4.1 공통 좌표

| 규격 | 값 |
|---|---:|
| SVG `viewBox` | `0 0 1024 1536` |
| 캔버스 중심 | `(512, 768)` |
| 리그·의상 중심선 | `x=526` |
| 공통 허리 앵커 | `W=(526,858)` |
| 허리 접속 폭 | `x=382~670` |
| 표준 허리 밴드 | `y=842~878` |
| 목표 겹침 | `24~30px` |
| 허용 겹침 | `20~36px` |
| 좌우 접속 오차 | `±6px` 이하 |
| 앵커 이동 오차 | `4px` 이하 |
| 보이는 실루엣 단차 | `8px` 이하 |
| 신체 누출·침범 | `2px` 이하 |
| 바닥 기준 | `y=1450±2` |

### 4.2 안전 영역

| 영역 | 좌표 |
|---|---|
| 전체 투명 출력 안전 영역 | `x=64~960`, `y=48~1488` |
| 기본 신체 영역 | `x=272~752`, `y=96~1452` |
| 팔·꼬리·가방 확장 영역 | `x=208~816`, `y=112~1452` |

### 4.3 착용 방식 계약

모든 상·하의는 다음 중 하나의 `waistMode`를 가져야 한다.

| `waistMode` | 사용 예 | 연결 규칙 |
|---|---|---|
| `over` | 일반 맨투맨·후드 | 상의 옷자락이 허리 밴드 위를 24~30px 덮음 |
| `tucked` | 셔츠를 넣어 입는 조합 | 하의 허리 앞 레이어가 상의 끝을 덮음 |
| `open` | 앞이 열린 재킷 | 내부 상의와 하의 접속부가 보이도록 양쪽 앞판 분리 |
| `long-over` | 긴 외투 | 하의 허리선은 가리되 다리 움직임과 손 레이어는 유지 |

아이템마다 CSS `translate`, `scale`, 별도 오프셋을 추가하는 방식은 금지한다. 맞지 않는 에셋은 원본 연결 경로를 다시 그린다.

## 6. 1화 최종 16개 의상 구성

현재 8개를 보정하고 신규 8개를 추가한다. 각 슬롯은 같은 상황 안에서도 적합성의 정도가 다르게 보이도록 구성한다.

### 6.1 겉옷

| 역할 | 아이템 | 상태 | 구조 훈련장에서의 판단 | 주요 제작 위험 |
|---|---|---|---|---|
| 최적 | 구조 훈련복 | 기존 보정 | 시인성·활동성·보호를 함께 제공 | `open/over` 앞판과 허리 접속 |
| 허용 대안 | 민트 바람막이 | 신규 | 가볍고 움직이기 좋지만 구조복보다 시인성이 낮음 | 밑단과 소매 볼륨 |
| 부분 적합 | 활동 후드 | 신규 | 활동성은 좋으나 보호·시인성이 부족함 | 후드 뒤 레이어와 목 가림 |
| 명확한 부적합 | 단정한 재킷 | 기존 보정 | 단정하지만 빠른 구조 활동에는 불편함 | `tucked`와 `open` 조합 |

### 6.2 하의

| 역할 | 아이템 | 상태 | 구조 훈련장에서의 판단 | 주요 제작 위험 |
|---|---|---|---|---|
| 최적 | 검정 활동 바지 | 기존 보정 | 움직임과 다리 보호에 적합 | 현재 폭을 공통 허리 규격에 맞춤 |
| 허용 대안 | 보호 카고 바지 | 신규 | 보호와 수납에 좋지만 조금 무거움 | 주머니와 손의 레이어 |
| 부분 적합 | 베이지 반바지 | 신규 | 움직임은 좋으나 다리 보호가 부족함 | 다리 노출 경계 |
| 명확한 부적합 | 긴 치마 | 기존 보정 | 활동 중 걸리거나 움직임을 방해할 수 있음 | 꼬리·발과의 겹침 |

### 6.3 신발

| 역할 | 아이템 | 상태 | 구조 훈련장에서의 판단 | 주요 제작 위험 |
|---|---|---|---|---|
| 최적 | 운동화 | 기존 보정 | 달리기와 지면 접지에 적합 | 발목과 바짓단 접촉 |
| 허용 대안 | 등산화 | 신규 | 보호·접지가 좋지만 운동화보다 무거움 | 높은 발목과 바짓단 |
| 부분 적합 | 검정 구두 | 신규 | 발을 덮지만 빠른 활동과 접지에는 불리함 | 형태가 정답처럼 고급스럽게 보이지 않게 균형 |
| 명확한 부적합 | 실내 슬리퍼 | 기존 보정 | 벗겨지기 쉽고 발 보호가 부족함 | 발가락·발등 노출 |

### 6.4 소품

| 역할 | 아이템 | 상태 | 구조 훈련장에서의 판단 | 주요 제작 위험 |
|---|---|---|---|---|
| 최적 | 안전모 | 기존 보정 | 머리 보호에 직접 도움 | 귀·머리 앞뒤 레이어 |
| 허용 대안 | 반사 밴드 | 신규 | 다른 사람에게 잘 보이게 함 | 팔·소매 앞뒤 레이어 |
| 부분 적합 | 호루라기 | 신규 | 신호 전달에는 도움되지만 보호를 대신하지 못함 | 목줄·상의·손의 교차 |
| 명확한 부적합 | 캔버스 가방 | 기존 보정 | 움직임을 방해하고 훈련 목적에 불필요함 | 몸 앞뒤 스트랩 레이어 |

### 6.5 신규 제작 수량

## 7. 선택·점수·시간 규칙

### 7.1 1화가 가르칠 네 가지 기능

- 시인성: 다른 사람에게 잘 보이는가
- 활동성: 빠르고 안전하게 움직일 수 있는가
- 보호: 머리·몸·발을 위험에서 보호하는가
- 접지: 뛰거나 멈출 때 미끄러지지 않는가

### 7.2 점수 구성

| 평가 | 비중 | 내용 |
|---|---:|---|
| TPO 기능 적합성 | 70% | 네 기능을 조합별로 평가 |
| 이유 이해 | 20% | 결과 화면의 기능 질문 또는 이유 선택 |
| 시간 보너스 | 10% | 목표 시간 안에서만 차등 지급 |

슬롯별 아이템은 대략 다음 범위를 갖되, 최종 점수는 조합 간 상호작용도 반영한다.

| 역할 | 권장 기여도 |
|---|---:|
| 최적 | 100% |
| 허용 가능한 대안 | 80~90% |
| 부분 적합 | 45~70% |
| 명확한 부적합 | 0~30% |

치명적인 안전 부적합이 포함된 조합은 다른 아이템이 좋아도 고득점에 도달하지 못한다. 단, 피드백은 “이 옷은 나쁘다”가 아니라 “구조 훈련에서는 발을 단단히 잡아 주는 신발이 필요하다”처럼 상황과 기능으로 설명한다.

### 7.3 시간 규칙

| 모드 | 목표 시간 | 시간 종료 시 |
|---|---:|---|
| 스토리 첫 시도 | 90초 | 시간 보너스만 0점, 선택은 계속 가능 |
| 다시 도전 | 60초 | 시간 보너스만 0점, 선택은 계속 가능 |

카운트다운은 첫 시도에서 위협적으로 깜빡이지 않는다. 시간 자체보다 생각하고 설명하는 경험을 우선한다.

### 7.4 UI 배치

- 데스크톱: 한 행에 카드 4개
- 태블릿·모바일: 가로 스크롤 없이 2×2
- 선택 카드의 그림은 착용 원본에서 파생한다.
- 선택 전부터 정답 카드만 더 밝거나 화려하게 만들지 않는다.
- 캐릭터는 왼쪽 패널 높이의 약 58~65%를 유지한다.
- 카드 선택 시 캐릭터 변화가 즉시 보이며, 목표 반응 시간 P95는 100ms 이하이다.
- 슬롯을 이동해도 이미 선택한 옷과 선택 수가 명확하게 유지된다.

## 8. 에셋 제작 규칙

1. 카드 썸네일과 착용 이미지는 같은 SVG 마스터에서 파생한다.
2. 모든 SVG는 `viewBox="0 0 1024 1536"`을 사용한다.
3. 좌표는 2px 그리드에 맞추고 앵커 오차가 4px을 넘으면 반려한다.
4. 외곽선은 6px, 내부선은 3~4px을 기본으로 한다.
5. 아이템별 SVG는 gzip 80KB 이하를 권장하고 120KB를 넘기지 않는다.
6. 아이템 전체 경로 수는 220개 이하로 한다.
7. 필터, 내장 비트맵, `foreignObject`는 사용하지 않는다.
8. `clipPath`와 `mask` ID는 에셋별로 고유해야 한다.
9. 썸네일은 384×240 WebP, 35KB 이하를 목표로 한다.
10. 신체는 하나의 기준 SVG를 쓰고 표정만 그룹 단위로 교체한다.

## 9. 조합 검증 범위

슬롯별 4개 아이템을 기준으로 다음 범위를 검수한다.

| 검증 대상 | 계산 | 수량 |
|---|---:|---:|
| 완성 코디 | `4×4×4×4` | 256 |
| 미선택 포함 상태 | `5×5×5×5` | 625 |
| 표정 3종 합성 | `625×3` | 1,875 |
| 고위험 조합 브라우저 캡처 | `32조합×3표정×3화면` | 288 |

전체 625개 상태는 접촉 시트로 자동 생성해 빠르게 훑고, 고위험 32개 조합은 데스크톱·태블릿·모바일에서 픽셀 비교한다.

고위험 조합에는 다음이 반드시 포함된다.

- 모든 겉옷 × 모든 하의 16개 조합
- `tucked`, `open`, `long-over`의 경계 조합
- 긴 치마 × 모든 신발
- 높은 등산화 × 모든 하의
- 반사 밴드 × 소매가 큰 상의
- 호루라기 × 후드·열린 재킷
- 안전모 × 표정 3종
- 가방 × 꼬리·손 레이어

## 10. 수정 실행 게이트

기존 프로젝트의 Gate 6·7과 혼동하지 않도록 이번 수정 작업은 `R0~R6`로 표기한다.

### R0. 규격 동결

작업:

- `W=(526,858)` 허리 앵커와 접속 폭을 가이드 SVG로 만든다.
- `waistMode`와 레이어 명세를 데이터 스키마에 정의한다.
- 16개 아이템의 역할과 TPO 기능 점수를 확정한다.

통과 조건:

- 미술·개발·기획이 같은 가이드 파일을 사용한다.
- 런타임 개별 transform을 쓰지 않는다는 원칙에 합의한다.

### R1. 회색조 4아이템 연결 프로토타입

작업:

- 기존 구조 훈련복, 활동 바지와 신규 상의 1개, 신규 하의 1개를 회색조로 만든다.
- `over`, `tucked`, `open` 연결을 먼저 검증한다.

통과 조건:

- 네 가지 상·하의 조합에서 겹침 20~36px
- 접속 오차 ±6px 이하
- 단차 8px 이하
- 신체 누출 2px 이하

이 단계에서 실패하면 색상과 나머지 신규 에셋 제작을 시작하지 않는다.

### R2. 기존 8개 마이그레이션

작업:

- 기존 에셋을 새 허리·레이어 규격에 맞춘다.
- 카드 썸네일을 착용 마스터에서 다시 생성한다.

통과 조건:

- 기존 8개가 새 수달 리그에서 자연스럽게 보인다.
- 카드와 착용 모습 동일성 평가 90% 이상
- 현재 정상인 표정·배경·선택 동작에 회귀 오류가 없다.

### R3. 신규 8개 제작

작업:

- 신규 에셋을 선화 → 단색 → 최종 색상 순서로 제작한다.
- 각 단계마다 4×4 상·하의 접속표를 갱신한다.

통과 조건:

- 16개 모두 파일 규격·용량·경로 수 기준 충족
- 정답 여부와 무관하게 모든 의상이 매력적이고 자연스럽게 착용됨
- 카드 그림만 보고 저학년이 아이템을 85% 이상 구분

### R4. 선택지·점수·UI 통합

작업:

- 1화 카탈로그의 2개 예외를 제거하고 슬롯당 4개로 변경한다.
- 4단계 적합성, 조합 보너스·제한, 시간 보너스를 데이터로 구현한다.
- 데스크톱 4열, 모바일 2×2 배치를 적용한다.

통과 조건:

- 256개 완성 조합이 모두 채점됨
- 100점 대표 조합 1개와 통과 조합 8~24개 존재
- 명확한 안전 부적합 조합이 고득점하지 않음
- 모바일에서 가로 스크롤 없이 선택 가능

### R5. 자동·시각 회귀 검수

작업:

- SVGO, Sharp 또는 resvg, pixelmatch, Playwright 기반 검사를 구성한다.
- 625개 상태 접촉 시트와 고위험 288개 브라우저 캡처를 생성한다.

즉시 실패 조건:

- 겹침이 20px 미만 또는 40px 초과
- 앵커 이동이 4px 초과
- 신체 누출·침범이 2px 초과
- 귀·손·꼬리·발의 레이어 오류 1건 이상
- 카드와 착용 이미지가 다른 아이템처럼 보임
- 선택 반응 P95가 100ms 초과
- 레이아웃 이동량 CLS가 0.01 초과

### R6. 아동 사용성·학습 검증

대상:

- 초등 저학년 8명 이상
- 초등 중학년 8명 이상

## 13. 승인 후 첫 작업

계획 승인 후 바로 신규 에셋 8개를 그리지 않는다. 먼저 다음 세 산출물만 만든다.

1. 공통 허리·손·발·꼬리 앵커가 표시된 리그 가이드 SVG
2. 구조 훈련복·활동 바지·신규 상의 1개·신규 하의 1개의 회색조 연결 프로토타입
3. 4×4 상·하의 조합 접촉 시트

이 세 가지가 R1을 통과하면 기존 8개 보정과 신규 8개 제작으로 넘어간다. 이렇게 해야 같은 연결 오류를 16개 에셋에 반복하지 않는다.
