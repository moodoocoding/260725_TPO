# TPO 스타일 구조대 어린이 현장 대체 시뮬레이션 결과

검증일: 2026-07-27

대상 버전: `00bb91c` 기반 스토리 모드 13화

## 1. 목적과 한계

실제 어린이를 모집한 현장 플레이 테스트를 진행할 수 없는 조건에서, 서로 다른 읽기 능력과 선택 습관을 가진 가상 어린이 대리 사용자가 스토리 모드 전체를 반복 플레이하도록 시뮬레이션했다.

이 검사는 다음과 같은 구조적 문제를 찾는 데 사용한다.

- 특정 카드 위치만 반복해서 눌러도 계속 통과하는가
- 글을 꼼꼼히 읽는 아이가 규칙 때문에 억울하게 실패하는가
- 그림이나 색상부터 보는 아이도 피드백을 통해 회복할 수 있는가
- 읽기 지원이 필요한 아이에게 진행 불가능한 에피소드가 있는가
- 실패 후 재도전 안내가 실제 점수 향상으로 이어지는가
- 특정 에피소드가 다른 에피소드보다 지나치게 어렵거나 쉬운가

단, 이 결과는 실제 어린이의 재미, 감정, 집중 지속 시간, 자연스러운 언어 이해를 직접 관찰한 결과가 아니다. 따라서 실제 현장 테스트와 완전히 같다고 해석해서는 안 된다.

## 2. 대리 사용자 유형

| 유형 | 연령 가정 | 주요 행동 |
| --- | --- | --- |
| 꼼꼼히 읽는 아이 | 10~11세 | 문자와 아이템 설명을 대부분 읽고 여러 단서를 함께 비교한다. |
| 일반적인 독자 | 8~9세 | 핵심 문장을 읽지만 일부 단서나 설명은 건너뛴다. |
| 읽기 지원이 필요한 아이 | 6~7세 | 짧은 단어와 익숙한 안전 기능을 중심으로 판단한다. |
| 그림부터 고르는 아이 | 7~9세 | 그림, 색상, 카드 위치를 먼저 보고 설명은 일부만 읽는다. |
| 빠르게 누르는 아이 | 8~10세 | 첫 시도에서는 앞쪽 카드를 빠르게 누르고 재도전 때 일부 피드백을 반영한다. |
| 피드백으로 배우는 아이 | 8~10세 | 첫 판단은 보통 수준이지만 실패 이유를 적극적으로 다음 시도에 적용한다. |

각 유형은 13개 에피소드를 에피소드당 240회씩 수행했다. 한 번의 여정에서 최대 3회까지 시도했으며, 총 18,720개 여정과 약 24,461회의 코디 시도가 실행됐다. 난수는 고정된 시드를 사용하므로 같은 코드와 데이터에서는 같은 결과가 재현된다.

## 7. 결론

현재 스토리 모드는 현장 대체 시뮬레이션 기준으로 다음 조건을 충족한다.

- 글과 단서를 읽는 아이는 막힘 없이 전체 이야기를 완료할 수 있다.
- 읽기 지원이 필요한 아이와 그림 중심의 아이도 피드백을 이용하면 대부분 회복한다.
- 앞 카드만 누르는 위치 전략은 안정적인 승리 전략이 아니다.
- 실패는 무작위 벌점이 아니라 부족한 안전·상황 단서를 다시 확인하게 만드는 학습 단계로 작동한다.
- 13개 중 진행이 사실상 불가능한 에피소드는 없다.

현재 결과만으로 점수 규칙이나 아이템 구성을 완화할 필요는 없다. 추후 실제 관찰 기회가 생기면 1화, 7화, 11화에서 두 번째 실패 후 피로감이 생기는지 우선 확인한다.
