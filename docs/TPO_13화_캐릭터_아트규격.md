# TPO 스토리 모드 13화 캐릭터 아트 규격

> 목적: 각 에피소드에서 옷을 입는 캐릭터를 실제 요청자와 일치시키면서, 1화 수달용 의상 리그를 모든 캐릭터가 공통으로 사용하게 한다.
> 범위: 캐릭터 매핑과 아트 제작 규격만 확정한다. 코드와 기존 에셋은 이 문서에서 수정하지 않는다.

## 1. 점검 결과와 기준 선택

점검 대상:

- `lib/story-catalog.json`
- `public/art/v2`
- `public/art/v4/episodes/rescue-team-trial`
- `art-source/character-rig/otter-v1`
- `docs/TPO_스토리모드_4인_통합_스토리바이블.md`

현재 2~13화의 `v2` 캐릭터는 사람형이고, 의상도 사람형의 긴 다리와 낮은 발 위치에 맞춰져 있다. 반면 1화의 `v4` 수달은 짧은 다리와 높은 발 위치를 사용하는 별도 리그다. 따라서 `v2` 캐릭터만 동물로 바꾸거나 `v2` 의상을 그대로 수달 몸에 얹는 방식은 허용하지 않는다.

공통 기준은 **현재 1화 `v4` 수달 리그**로 정한다. 2~13화의 동물 캐릭터는 머리와 얼굴만 달라지고, 목 아래 몸통·팔·손·허리·다리·발은 1화 수달과 같은 좌표와 실루엣을 사용한다. 각 에피소드의 16개 의상도 이 공통 리그에 맞춘 착용 마스터가 필요하다.

### 주의해야 할 현재 규격 충돌

- `otter-v1/rig-spec.json`과 실제 `v4` 수달 베이스의 맨발 바닥은 `y=1278`이다.
- `revision-r0/wear-contract.json`의 `groundY=1450`은 `v2` 사람형 신발 위치에 가깝고, 현재 `v4` 수달과 일치하지 않는다.
- 실제 `v4` 신발 4종의 밑창 하단은 `y=1305~1312`다.

그러므로 공통 동물 리그에서는 아래 값을 사용한다.

- 맨발 기준선: `y=1278`
- 신발 착용 밑창 기준선: `y=1308 ± 4`
- `y=1450`은 동물 리그에서 사용 금지

`y=1450`을 계속 사용하려면 1화 수달 베이스와 `v4` 16개 착용 레이어를 포함한 모든 에셋을 한꺼번에 다시 그려야 한다. 두 기준을 섞어서는 안 된다.

### 2.2 종별로 바꿀 수 있는 부분

- 머리 내부의 털색, 얼굴 무늬, 코와 주둥이 모양
- 정해진 귀 앵커를 중심으로 한 작고 접히는 귀
- 표정 3종
- 몸 뒤에서만 보이는 짧은 꼬리 또는 꼬리 없음

### 2.3 종별로 바꾸면 안 되는 부분

- 목의 위치와 폭
- 어깨, 팔꿈치, 손목, 손의 크기와 각도
- 몸통, 허리, 골반의 외곽선
- 다리 길이와 폭
- 발목, 발, 신발의 크기와 위치
- 의상 아래로 보이는 배와 팔다리의 경계

긴 귀, 뿔, 갈기, 큰 꼬리처럼 공통 모자·후드·가방과 충돌하는 특징은 사용하지 않는다. 고양이와 여우의 삼각 귀도 머리 위 `y=159`를 넘지 않고, 모자 착용 시 `ear-mask`로 완전히 정리되는 크기만 허용한다.

아래 좌표는 2~13화 신규 얼굴 제작에 적용할 공통 제안값이다.

| 요소 | 기준 |
| --- | --- |
| 얼굴 안전영역 | `x=350~702`, `y=315~525` |
| 왼쪽/오른쪽 눈 중심 | `(416,405)` / `(636,405)` |
| 코 중심 | `(526,458)` |
| 입 중심 | `(526,500)` |

종의 개성은 이 안전영역 안의 무늬와 주둥이 형태로 표현한다. 눈 위치를 종마다 움직여 별개의 얼굴 비율을 만들지 않는다. 보안경, 수면 안대, 스키 고글 등 얼굴 소품은 이 공통 좌표를 기준으로 모든 캐릭터에 동일하게 맞아야 한다.

## 4. 표정 규격

모든 요청자는 같은 세 표정을 가진다.

- `ready`: 눈을 뜨고 작은 미소. 불안·졸림·성급함을 과장하지 않는다.
- `success`: 눈꼬리가 부드럽게 올라가거나 초승달 모양이 되고 입을 조금 연다.
- `retry`: 눈썹을 안쪽으로 아주 조금 모으고 입을 작게 다문다. 울음, 눈물, 수치심 표현은 금지한다.

종 고유의 얼굴 무늬는 세 표정에서 위치·크기·색이 변하지 않는다. 표정 파일을 각각 생성하더라도 몸과 머리 외곽은 픽셀 단위로 완전히 동일해야 한다.

## 5. 접근성 대비 규격

### 5.1 캐릭터

- 공통 외곽선: `#14213D`, 기준 캔버스에서 6px
- 내부선: 3~4px
- 얼굴 특징과 얼굴 바탕의 명도 대비: 가능하면 `4.5:1` 이상
- 캐릭터 외곽과 캐릭터 바로 뒤 배경의 비텍스트 대비: `3:1` 이상
- 흰색 또는 회백색 캐릭터는 순백 배경에 두지 않는다. 배경의 캐릭터 안전영역을 중간 명도의 색으로 조정한다.
- 빨강/초록, 파랑/보라 같은 색 차이만으로 인물을 구분하지 않는다. 귀, 이마 무늬, 주둥이, 얼굴 패치처럼 형태 단서를 함께 사용한다.
- 뺨 색, 속눈썹, 리본으로 성별을 구분하지 않는다.

### 5.2 의상과의 관계

- 털색은 정답 점수와 관계가 없어야 한다.
- 털 무늬가 의상의 반사띠, 단추, 허리선으로 오인되지 않게 의상 아래에서는 몸 무늬를 숨긴다.
- 검은 의상 위 검은 팔, 흰 의상 위 흰 얼굴처럼 경계가 사라질 때도 공통 네이비 외곽선을 유지한다.
- 카드 썸네일에는 캐릭터 고유 털색을 섞지 않는다. 같은 아이템은 모든 요청자에게 같은 색과 형태로 보여야 한다.

## 8. 제작 및 승인 순서

1. 12명의 `ready` 머리 시안을 공통 수달 몸 위에 회색 의상으로 합성한다.
2. 머리 외곽, 귀, 목, 얼굴 소품 호환성을 승인한다.
3. 각 캐릭터에 공통 테스트 의상 6종을 입힌다: 후드, 열린 재킷, 긴 상의, 긴 바지, 장화, 머리 소품.
4. 허리·손목·발목·귀의 틈과 관통이 0건일 때만 표정 3종을 만든다.
5. 각 에피소드의 16개 아이템을 동물 공통 리그로 옮긴다.
6. 에피소드별 정답·부분정답·오답 코디를 실제 배경 위에서 확인한다.

### 승인 수치

- 캐릭터별 의상 이동값: `0`
- 허리 앵커 오차: `≤4px`
- 허리 좌우 오차: `≤6px`
- 허리 가시 단차: `≤8px`
- 몸 노출: `≤2px`
- 신발 밑창: `y=1308 ±4`
- 머리 또는 귀의 안전영역 이탈: `0`
- 모자·고글·안대·후드 관통: `0`
- 카드와 착용 모습의 형태 불일치: `0`

## 9. 금지사항

- 2~13화에서 요청자 대신 하루가 계속 옷을 입는 연출
- 5화에서 하루를 새 색이나 새 종으로 다시 만드는 것
- `v2` 사람 몸, `v4` 수달 몸, 신규 동물 몸을 에피소드마다 혼용하는 것
- `v2` 사람용 착용 레이어를 신규 동물 베이스 위에 그대로 합성하는 것
- 종마다 몸통 폭, 팔 길이, 손·발 크기, 허리 또는 신발 위치를 바꾸는 것
- 긴 토끼 귀, 사슴뿔, 큰 여우 꼬리처럼 공통 의상 밖으로 크게 이탈하는 특징
- 영구 안경, 리본, 목걸이 등 선택 아이템과 충돌하는 기본 장식
- 캐릭터별 CSS `translate`, `scale`, `clip-path`로 착용 오차를 가리는 것
- 표정별로 머리 크기나 몸 위치가 달라지는 것
- 생성된 전신 캐릭터마다 의상을 다시 그려 넣는 것
- 털색이나 성별 인상으로 정답 의상을 암시하는 것
- 장례식 요청자를 우울한 종이나 어두운 색으로만 표현하는 등 상황을 성격으로 고정하는 것

## 10. 통합 결론

1화와 5화는 같은 하루 수달을 사용한다. 나머지 에피소드는 민준 강아지, 소미 햄스터, 지우 쿼카, 서준 펭귄, 예린 북극곰, 다온 레서판다, 은호 은여우, 하린 다람쥐, 도윤 오소리, 채원 삼색고양이, 태오 검은발족제비로 확정한다.

이 캐릭터들은 서로 다른 전신을 만드는 것이 아니라 **같은 1화 수달 몸에 요청자별 머리·얼굴·색을 적용한 공통 리그 캐릭터**다. 이 원칙을 지켜야 13개 에피소드의 208개 선택 아이템이 캐릭터마다 다시 어긋나지 않는다.
