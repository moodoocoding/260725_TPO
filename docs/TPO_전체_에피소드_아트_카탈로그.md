# TPO 스타일 구조대 전체 에피소드 아트 카탈로그

## 1. 적용 범위

- 캐릭터: 공통 베이스 1종, 표정 3종
- 스토리: 프롤로그 1편 + 4개 챕터 12편, 총 13개 에피소드
- 아이템: 재사용 가능한 의상·신발·소품 94종
- 착용 레이어: 101개
- 아이템 썸네일: 94개
- 에피소드 배경: 13개
- 전체 이미지: WebP 212개

## 2. 에셋 규격

| 종류 | 규격 | 배경 |
| --- | --- | --- |
| 캐릭터·착용 레이어 | 1024 × 1536 | 투명 |
| 아이템 썸네일 | 512 × 384 | 투명 |
| 에피소드 배경 | 1920 × 1440 | 불투명 |

착용 레이어와 캐릭터는 같은 캔버스를 사용한다. 모든 아이템은 `back`, `main`, `front` 중 필요한 레이어만 가지며, 런타임이 정해진 순서대로 합성한다.

## 3. 에피소드 배경

1. 구조대 입단 시험 — 구조대 본부
2. 체육 수업 준비 — 학교 운동장
3. 잠잘 준비 — 아늑한 침실
4. 친구 생일 파티 — 생일 파티장
5. 비 오는 날의 심부름 — 비 오는 거리
6. 여름 워터파크 — 야외 물놀이장
7. 겨울 스키 교실 — 설원과 스키장
8. 결혼식 화동 — 예식장
9. 가족 장례식 — 추모 공간
10. 설날 세배 — 한옥 마당
11. 과학실 실험 — 과학실
12. 가족 요리 시간 — 가정 주방
13. 좀비 도시 탈출 — 어두운 도시와 대피로

## 4. 파일 구조

```text
public/art/v2/
├─ character/
│  ├─ base.webp
│  └─ faces/{ready,success,retry}.webp
├─ items/{item-id}/
│  ├─ thumb.webp
│  └─ wear-{back,main,front}.webp
├─ episodes/{episode-slug}/background.webp
└─ art-manifest.json
```

## 5. 재생성과 검증

- `npm run story:generate`: 13개 에피소드와 아이템 카탈로그 재생성
- `npm run story-art:generate`: 카탈로그를 기준으로 v2 이미지 전체 재생성
- `npm run story:validate`: 콘텐츠·규칙·3,328개 코디 조합 검증
- `npm run story-art:validate`: 경로·파일 수·규격·투명도·용량 검증

아이템을 추가할 때는 카탈로그 생성 스크립트에 한 번만 등록한다. 그 뒤 카탈로그와 아트를 재생성하면 썸네일, 착용 레이어, 매니페스트가 같은 ID로 함께 만들어진다.
